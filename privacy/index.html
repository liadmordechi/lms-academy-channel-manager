This policy describes the privacy practices of LMS Academy Channel Manager (the “Tool”), an internal software utility that LMS ACADEMY LLC uses to manage its own YouTube channel.

2. What the Tool does

The Tool is a private, internal utility. It is not a product, it is not distributed or sold, and it is not available to the public. It runs locally on the channel owner's own computer and is operated by one person: the owner of the LMS Academy channel.

Its only function is to help LMS ACADEMY LLC publish and organize its own soccer training videos on its own YouTube channel. Specifically, it can:

  • Upload videos to the LMS Academy channel
  • Set custom thumbnails on those videos
  • Edit titles, descriptions, tags and categories of those videos
  • Create playlists and add its own videos to them
  • Upload subtitle tracks to its own videos
  • Read back the channel's own video list, upload status and public statistics

3. Whose information the Tool accesses

Only the channel owner's own information, and only their own channel.

The Tool authenticates through Google OAuth 2.0 using the credentials of the LMS Academy channel owner. It accesses:

DataPurpose
The owner's own channel name, ID and public statisticsConfirm the correct channel is connected; report status
Metadata of videos on that channel (titles, descriptions, tags, visibility, processing state)Display and edit them
Video and image files the owner selects on their own computerUpload them to that channel

The Tool does not access, collect, request, or process information belonging to any other person, viewer, subscriber, channel, or third party. It has no users other than the channel owner. It does not read comments, subscriber lists, private viewer data, or any other individual's information. It does not scrape YouTube and does not aggregate data across channels.

4. Google user data

Access

The Tool requests the following Google OAuth scopes, and no others:

  • youtube.upload — upload videos to the owner's own channel
  • youtube — read and edit the owner's own channel content and playlists
  • youtube.force-ssl — required by the API for subtitle operations

Use

Data obtained through these scopes is used exclusively to perform the actions the channel owner explicitly requests, at the moment they request them. It is not used for any other purpose.

Storage

The Tool stores an OAuth access token and refresh token locally on the channel owner's own computer, in a private directory readable only by that operating system account. It also stores a local counter of daily API usage. It stores no video content, no personal information, and no user data on any server. There is no backend, no database, and no cloud storage of any kind.

Sharing

The Tool transmits data only between the channel owner's computer and Google's own YouTube Data API. No data is ever sold, rented, shared, transferred, or disclosed to any third party, advertiser, analytics provider, data broker, or AI model training process.

Retention and deletion

Stored credentials remain on the owner's computer until the owner deletes them or revokes access. The channel owner may revoke the Tool's access at any time at myaccount.google.com/permissions, which immediately and permanently ends its ability to access any Google data. Deleting the local credential files removes all stored tokens.

5. Limited Use commitment

LMS Academy Channel Manager's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. YouTube Terms of Service

By using this Tool, LMS ACADEMY LLC agrees to be bound by the YouTube Terms of Service. Users are also directed to the Google Privacy Policy, which governs Google's own handling of data.

7. Children's privacy

LMS ACADEMY LLC serves youth athletes, and published video content may feature children with the consent of their parents or guardians, obtained separately by the academy. The Tool itself collects no information from or about children. It handles only video files the channel owner has already chosen to publish, and the metadata attached to them. It performs no tracking, profiling, targeting, or analytics of any individual, of any age.

8. Security

Credentials are stored locally with restricted file permissions accessible only to the channel owner's operating system account. All communication with Google APIs uses HTTPS. No credentials are embedded in source code or transmitted anywhere other than to Google.

9. Changes to this policy

If the Tool's data practices change, this page will be updated and the “Last updated” date above revised.
